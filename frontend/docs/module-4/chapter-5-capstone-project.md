# Chapter 5 - Capstone Project — Autonomous Humanoid

This chapter culminates the module with a capstone project: building and demonstrating an autonomous humanoid robot capable of executing complex tasks via natural language commands in a simulated environment.

## Combine Perception, Navigation, Manipulation, and VLA

Integrate all previously learned components: multi-modal perception, ROS 2 communication, voice-to-action systems, and LLM-guided cognitive planning into a unified robotic system.

## Simulated Humanoid Executes a Complex Voice Command

Demonstrate the end-to-end VLA pipeline by having a simulated humanoid robot (e.g., in Isaac Sim) respond to a multi-step, high-level voice command (e.g., "Find the water bottle on the table and bring it to me").

## Obstacle Avoidance, Object Identification, and Manipulation

Focus on the robot's ability to navigate dynamic environments, accurately identify target objects, perform precise manipulation tasks, and avoid obstacles while executing the voice command.

## Optional Edge Deployment on Jetson Orin or Physical Robot Proxy

Explore the process of deploying the developed VLA pipeline onto edge hardware like an NVIDIA Jetson Orin or integrating it with a physical robot proxy (e.g., quadruped, robotic arm) for real-world testing. This section highlights the considerations and adaptations needed for hardware deployment.
