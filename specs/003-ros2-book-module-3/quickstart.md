# Module 3 Quickstart

This guide provides a quick overview of the steps required to get started with Module 3.

## 1. Prerequisites

Before you begin, ensure you have the following installed and configured:

-   **Hardware**:
    -   An NVIDIA RTX-enabled GPU. See `research.md` for per-chapter recommendations.
-   **Software**:
    -   Ubuntu 22.04 LTS
    -   ROS 2 Humble or Iron
    -   NVIDIA Isaac Sim (latest version recommended)
    -   NVIDIA Isaac ROS

Refer to the official documentation for installation instructions for each software component.

## 2. Clone the Repository

If you haven't already, clone the book's repository to your local machine:

```bash
git clone <repository-url>
cd <repository-directory>
```

## 3. Running the Examples

Each chapter in this module contains runnable examples. To run an example, navigate to the chapter's directory and follow the instructions in the `README.md` file for that chapter.

For example, to run the first example in Chapter 2:

```bash
cd docs/module-3/chapter-2
# Follow instructions in the chapter's README or the book content
```

## 4. Key Activities

This module will guide you through the following key activities:

1.  **Setting up a simulation environment** in Isaac Sim.
2.  **Generating synthetic data** for training perception models.
3.  **Deploying GPU-accelerated perception pipelines** with Isaac ROS.
4.  **Implementing Visual SLAM** for localization.
5.  **Configuring Nav2** for autonomous navigation.

Enjoy your journey into the AI brain of humanoid robots!
