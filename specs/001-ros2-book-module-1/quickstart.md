# Quickstart: Module 1 - The Robotic Nervous System (ROS 2)

This quickstart guide provides an overview of Module 1, "The Robotic Nervous System (ROS 2)," which serves as the foundational unit for understanding how AI software interfaces with physical robotic bodies in humanoid and Physical AI systems.

## Module Objective

This module aims to provide a complete conceptual, architectural, and integration-level foundation of ROS 2. It covers:
- What ROS 2 is and why it's essential for robotics.
- ROS 2 core communication concepts (Nodes, Topics, Services, Actions).
- How AI agents connect to real robot hardware using `rclpy` and URDF.

## Getting Started

To get the most out of this module:
1.  **Review the Feature Specification**: For a detailed breakdown of the module's scope, requirements, and success criteria, please refer to: [specs/001-ros2-book-module-1/spec.md](specs/001-ros2-book-module-1/spec.md)
