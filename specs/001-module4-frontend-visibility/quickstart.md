# Quickstart Guide: Module 4 - Frontend Visibility (Docusaurus)

**Branch**: `001-module4-frontend-visibility` | **Date**: December 30, 2025 | **Spec**: /specs/001-module4-frontend-visibility/spec.md

This quickstart guide provides instructions to verify that Module 4 content is correctly displayed and navigable in the Docusaurus frontend.

## 1. Prerequisites

Ensure you have a working Docusaurus environment with all dependencies installed. This typically involves Node.js and the project's frontend dependencies.

## 2. Verify Docusaurus Configuration

1.  **Navigate to Frontend Directory**:
    ```bash
    cd frontend
    ```

2.  **Inspect `sidebars.ts`**:
    Open `frontend/sidebars.ts` and confirm that "Module 4" is correctly referenced within the `docs` sidebar array. It should follow the pattern of existing modules (e.g., using a `type: 'category'` entry with a `link` and `items` array). The `items` array likely uses an `autogenerated` entry for `module-4`.

3.  **Inspect Module 4 Frontmatter**:
    Check the `index.md` and chapter `.md` files within `frontend/docs/module-4/` to ensure they have correct YAML frontmatter, including `id`, `title`, and `sidebar_position` (if explicit ordering is used).

4.  **Inspect `_category_.json` (if autogenerated sidebar is used)**:
    If an `autogenerated` sidebar is used for `module-4`, verify the existence and content of `frontend/docs/module-4/_category_.json`, ensuring it has the correct `label` and `position`.

## 3. Run Docusaurus Locally

1.  **Install Dependencies (if not already done)**:
    ```bash
    npm install
    # or
    yarn install
    ```

2.  **Start Docusaurus Development Server**:
    ```bash
    npm run start
    # or
    yarn start
    ```
    This will typically open a browser window to `http://localhost:3000`.

## 4. Validate Frontend Visibility

1.  **Check Sidebar Navigation**:
    -   In your browser, navigate to the Docusaurus documentation section.
    -   Verify that "Module 4 - Vision-Language-Action (VLA) for Humanoid Robots" (or its configured label) appears in the sidebar, consistent with Modules 1-3.
    -   Expand "Module 4" and confirm all its chapters (e.g., Chapter 1, Chapter 2) are listed correctly.

2.  **Verify Page Navigation**:
    -   Click on the "Module 4" overview link and each chapter link in the sidebar.
    -   Confirm that each link navigates to the correct content page without any "Page Not Found" errors or broken links.
    -   Check the browser's URL to ensure correct routing for Module 4 content.

3.  **Check Docusaurus Build Logs**:
    -   In your terminal, observe the Docusaurus development server's output for any warnings or errors related to Module 4.
    -   (Optional, for final deployment check): Run `npm run build` or `yarn build` and verify the build completes without errors.

4.  **Verify No Regressions**:
    -   Navigate to Modules 1-3 and confirm they remain unchanged and fully functional.

## 5. Troubleshooting

-   If Module 4 does not appear, double-check `sidebars.ts` and the frontmatter in `index.md` and chapter files.
-   If links are broken, verify `id` fields in frontmatter match the expected `link` values in `sidebars.ts` or the autogenerated paths.
-   Refer to Docusaurus official documentation for sidebar configuration details.
